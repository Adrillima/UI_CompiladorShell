# ⚙🛠 UI_CompiladorShell

## Compilador do powershell com interface básica para ajudar.

Aqui tem o arquivo .exe e .ps1 do código. Fiquem a vontade para mudar do jeito que quiserem.

## ✨Fiz essa ferramenta com intuito de ajudar as pessoas na hora de compilar arquivos em shell, não seja impossível compilar na mão, mas como eu, acredito que a maioria dos dev's tem preguiça de fazer tudo.

Aqui está um script em PowerShell que cria uma interface gráfica (GUI) simples usando o Windows Forms. Ele possui os três campos de texto solicitados e um botão para acionar o comando Invoke-ps2exe.
Antes de rodar, certifique-se de que você tem o módulo instalado no seu computador. Caso não tenha, você pode instalá-lo rodando: Install-Module -Name ps2exe -Scope CurrentUser.
